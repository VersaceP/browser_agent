## 实现

### 确认输入

保留明确确认/取消/详情命令。其他自由文本调用独立 approval_classifier：复用现有 task_classifier 模型配置，
无该模型配置时按其现有回退方式使用 Browser 模型；去除推理开关，输出最多384 token，外层10秒超时，内部不重试。
只返回绑定当前 candidateHash 的五类决策。原话保留；失败/含糊时保持待确认，不批准也不重规划。
日志记录分类耗时与独立角色 usage。单测验证输出结构和绑定，不声称替身调用证明自然语言分类准确率。

### 审计与动态指导

新增 compiledFieldPolicies，直接从编译后 validators 提供各字段适用检查及其非空例外的交集。
审计说明区分普通非空、带完整缺失证据的空值、无证据为空。
特别说明 file_integrity 没有缺失例外，min_files 下限是1，计数覆盖组合目标文件而不是每个字段。
不能给可选视频额外强加独立必有一个文件的检查。guide 同步说明表达能力边界。
删除关键词触发的“用户只想诊断门禁”上下文：诊断范围由原始任务和批准合同表达。

### 连接状态与恢复

Fleet.list/Page.list/Page.getState 注册表同步只传播带 connection_fatal=true 的传输异常；
普通 RPC/页面失败保留原处理。致命异常进入已有启动失败预算，不再伪装成可无限重试的 Fleet 库存为空。
启动回执携带 transport code、requestSent、connectionFatal，保留业务 worker 尚未启动这一事实。

list_browser_agents 新增可选 refresh_connection=true，仅在外部服务恢复后显式使用：
通过注册、能力初始化、Fleet.list 核验同一端点和原 Fleet 引用，合并并发探测，核心探测10秒。
成功只清理带明确致命传输标记的启动失败记录；权限、普通 RPC、业务尝试记录不清理。
失效且空闲的连接转入既有 slot 恢复/初始化路径；运行中 worker 不被关闭。
成功探测不代表认证会话恢复，原有身份、page lease、phase 合同仍在正常 spawn 路径校验。
不派发 worker，不回放历史业务动作，不创建替代 Fleet。未恢复时只返回阻塞事实。

Page.create 失败的回执区分无获委派候选、探测未完成、有界范围内无可用页面；
不把 checkedPages=[] 表述成全局浏览器不可用。保持原停止/返回 Lead 路径，未放宽跨 worker 页面所有权。

### 上下文与检索

初次规划切换执行时，保留真实用户消息、批准计划全部内容和可信计划工具返回的 operatorFeedback；
移除历史 assistant 推理及旧工具回合。历史证据仍在 run.jsonl，交接附计划、状态、日志引用。
不新增摘要模型。普通文件内容中的 feedback 不会被提升为操作员意见。

从 a71 保存的首次 spawn 前上下文做离线交接：JSON 字符数513,564 → 28,384，保留“；确定”原反馈。
这是历史数据的确定性投影结果，不是 live token/延迟实测，也不包含 system prompt 和工具 schema。

本地搜索长行改为围绕真实正则命中截取，返回 matchColumn、snippetStartColumn、readHint 和截断标识；
file 与 db 共用片段逻辑，沿用原每条及总字节上限。没有检索次数门禁，也没有站点或选择器特判。
