## 修复依据

1. AX 解析保存 state，避免漏读已填写值导致反复重填；这是生成程序的数据读取缺陷。
2. 明确使用 Page.list.currentUrl、Page.getState.url；已有表单可恢复，不因修复再开入口。
3. 属性列表存在虚拟化；Input.scroll 返回 scroll-anchor-unavailable 后，使用当前可见候选内的滚轮坐标完成实际选择。具体默认锚点为何失败尚未取得平台命中测试证据。
4. 视频成功 UI 是媒体海报；预览图成功 UI 可是 CSS background。显式 attributes 查询取得 style，不能假定 DOM 结构视图返回全部属性。
5. 某段未确认结果时，先回读已有状态，未再次指派已经接收的文件。
6. Network.readApi 两次诊断返回 CLI_FAILED，未提供 HTTP 记录；不能据此断言上传请求失败。视频后续页面确认实际存在。CLI/平台错误诊断需另行核对。
